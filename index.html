Para o banco aparecer automaticamente em qualquer aparelho, faça isso uma vez:

1. Clique em "Baixar materiais.json" abaixo
2. Vá no GitHub → repositório estoque-3100
3. Clique em Add file → Upload files
4. Selecione o arquivo materiais.json e faça commit
5. Pronto! Todo celular que abrir o app já carrega automático ☁️
💡 Como usar
1. No SAP, exporte MB52 (ou qualquer relatório com código + descrição) para Excel
2. Abra o arquivo, selecione as colunas certas e copie (Ctrl+C)
3. Cole aqui e clique em Importar
4. Baixe o materiais.json e suba no GitHub — qualquer aparelho carrega automático ☁️
5. Vá para Contar e comece a escanear!
6. Ao terminar, exporte para Excel pela aba Exportar
